## 📌 Descripción del Proyecto
Este repositorio contiene los entregables del **Avance 2 (ATI2)** correspondiente a la Revisión Sistemática de la Literatura (RSL) sobre la aplicación de técnicas de Machine Learning para la predicción de conversión y priorización de prospectos (*leads*) en plataformas CRM (2020–2026).

  - [Matriz de extracción y cribado](Cribado_RSL_ML_CRM_Actualizado.xlsx): Matriz de cribado, criterios CI/CE, evaluación de calidad QA y formulario de extracción.

## 🔬 Resumen Metodológico (PICOC & PRISMA)
- **Ecuación de búsqueda (Scopus):** `TITLE-ABS-KEY` con combinaciones de Lead Scoring/Prioritization y Machine Learning/AI.
- **Flujo PRISMA:** 2,262 identificados → 2,258 excluidos en cribado → 4 evaluados a texto completo → 4 incluidos en el corpus final.
- **Puntuación QA:** 4.0/4.0 para los 4 estudios incluidos.
